# AI OffScreen 实施方案

> 配套文档：[`ARCHITECTURE.md`](./ARCHITECTURE.md)（做什么、为什么）。本文档回答**按什么顺序做、每一步做到什么程度算完成**。

---

## 0. 实施原则

1. **先走通，再做好。** M1 用最朴素的算法走通"电影 → 成片"全流程，丑没关系；之后每个里程碑只把某一段做深
2. **CLI 先于 UI。** 每个阶段先能从命令行跑、产物能在磁盘上看到，再做界面
3. **一个任务 = 一个 PR = 0.25–2 人天。** 超过 2 天的任务必须继续拆
4. **每个任务都有验收标准和"不做什么"。** 验收不过不算完成；范围外的想法进 `PARKING_LOT.md`
5. **里程碑有退出标准。** 不达标不开下一个里程碑
6. **每个 PR 必须通过 `make check`**（格式、lint、类型、单测、依赖契约）

### 估时假设

- 1 人开发 + AI 编码助手；估时为"专注人天"
- 硬件：一块 NVIDIA GPU（≥ 12GB 显存，24GB 更舒服）；没有 GPU 时把 ASR / 视觉 / TTS 切到云端适配器，任务不变
- 模型供应商：默认 MiniMax（Token Plan，文本 + 图片理解 + 语音合成），DeepSeek 备选；火山方舟 Coding Plan Key 不接入（见 `docs/PROVIDERS.md`）
- 测试素材：Blender 开源电影 Sintel（约 15 分钟）与 Tears of Steel（约 12 分钟），CC-BY 授权

## 3. M1 最小闭环（CLI，朴素实现）

- [ ] 再跑一次同样的命令，全部命中缓存，几秒内结束

## 5. M3 影片理解

**目标**：影片索引（L1）质量达到能支撑好文案、好选镜的程度，并且可以在 UI 中浏览和修正。

**退出标准**
- [ ] 镜头边界：在人工标注的 100 个切点样本上 F1 ≥ 0.9
- [ ] 人物：两部测试片的主要角色各自聚成独立的簇，命名后在 UI 中正确显示
- [ ] 场景摘要人工抽查 20 个，≥ 16 个准确
- [ ] `search_shots("龙在天上飞")` 前 5 个结果中 ≥ 3 个相关
- [ ] 每部片的分析费用与耗时有报告

**本里程碑不做**：硬字幕 OCR、人脸跟随裁剪、TMDB 以外的外部数据源、动作 / 运镜识别。

## 6. M4 文案系统

**目标**：文案风格可控、长度可控、事实可追溯，可以逐段编辑和重写。

**退出标准**
- [ ] 3 种风格 × 2 部测试片：时长误差 ≤ 10%，所有 scene_refs 有效
- [ ] 按评分表（钩子、连贯、准确、口语化、节奏，各 1–5 分）人工评分均分 ≥ 3.5
- [ ] 改一段 → 生成新版本，可与旧版本对比、可回退

**本里程碑不做**：多语言解说、自动生成标题党标题、多部电影合集文案。

## 11. 任务卡模板

每个任务开工前，把下面的卡片填好（可以直接贴给 AI 编码助手）。**卡片之外的事情一律不做。**

```markdown
## [M5-05] 时长适配器

**目标**：给定所选镜头和目标时长，产出精确到帧的裁剪方案。

**所属层 / 转换**：T3 编排 → 产出 L3 EditPlan.segments[].clips

**输入 / 输出契约**：
- 输入：list[CandidateShot]（带 start_ms/end_ms/score）、target_ms、output_fps、约束配置
- 输出：list[Clip]（src_in_ms/src_out_ms/speed）

**涉及模块**：`algo/fitting.py`、`tests/unit/test_fitting.py`

**不做什么**：
- 不做镜头挑选（那是打分 / 重排的事）
- 不调用任何模型、不做 IO
- 不处理转场

**验收标准**：
- [ ] 属性测试：任意合法输入，总时长 = 目标 ± 1 帧
- [ ] 单镜头时长落在 [0.8s, 4s]（源镜头本身更短时除外）
- [ ] 变速只在 [0.85, 1.15] 内
- [ ] `make check` 通过

**依赖**：M5-03
```

## 12. 日常工作流

```
1. 从当前里程碑挑一个依赖已满足的任务
2. 填任务卡（目标 / 所属层 / 契约 / 不做什么 / 验收）
3. 若要改 schema：先改 domain + fixture + 迁移，再改实现
4. 实现 + 测试（纯函数优先放 algo/）
5. make check 全绿
6. 在测试片上实际跑一次，看产物
7. 提交 PR（标题带任务 ID，如 "M5-05 时长适配器"）
8. 过程中冒出的新想法 → docs/PARKING_LOT.md，不在当前任务里做
```

### 里程碑结束时

1. 逐条核对退出标准，不达标就补任务，不开新里程碑
2. 跑黄金样片回归（M8 之前手动跑）
3. 评审停车场：哪些进下一里程碑，哪些继续搁置
4. 如果实现和架构文档出现偏差：要么改代码回归文档，要么写 ADR 更新文档 —— 二选一，不允许"文档说一套，代码做一套"
