# 想法停车场

> 开发中冒出的新想法都先写在这里，**不在当前任务里做**。每个里程碑结束时评审一次：纳入下一个里程碑、继续搁置，或者删除。
>
> 评审时先回答三个问题：
> 1. 它落在哪一层数据或哪一个转换上？（落不上的直接删）
> 2. 它是否违反 ARCHITECTURE §1.3 非目标？（违反的需要先写 ADR）
> 3. 不做它，成片质量或效率会差多少？
